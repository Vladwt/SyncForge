# Інструкція користувача SyncForge v1.0

**SyncForge** — це високонадійний менеджер синхронізації та резервного копіювання файлів для Windows 11. Головний фокус програми: збереження даних, захист від ненавмисних видалень, верифікація пристроїв та відмовостійкість.

---

## 1. Режими роботи

### Режим A: Безпечне одностороннє оновлення (Safe One-Way Update)
- Копіює нові файли з робочого ПК на зовнішній накопичувач.
- Оновлює змінені файли.
- **Ніколи не видаляє** файли на цільовому пристрої (захист від втрати даних).
- Створює резервні версії файлів перед їхньою заміною в папці `.syncforge_versions`.

### Режим B: Безпечна двостороння синхронізація (Safe Bidirectional Sync)
- Порівнює стан ПК та зовнішнього SSD з використанням збереженої базової лінії (Baseline).
- Зміни тільки на ПК оновлюють SSD; зміни тільки на SSD оновлюють ПК.
- При виявленні незалежних одночасних змін фіксується **конфлікт** (без автоматичного перезапису).
- Одностороннє видалення файлу **зберігає** його копію на іншій стороні.
- При першій синхронізації файли з однаковими іменами, але різним вмістом, переводяться в статус конфлікту для ручного вирішення.

### Режим C: Версійний холодний бекап (Versioned Cold Backup)
- Призначений для вторинних HDD-дисків.
- Зберігає повну хронологію версій файлів.
- Підтримує інкрементне додавання нових та змінених файлів.
- Ніколи не перезаписує та не видаляє заархівовані дані на HDD.

---

## 2. Ідентифікація пристроїв (SSD / HDD)

SyncForge не покладається на літери дисків (наприклад, `E:\` чи `F:\`), оскільки Windows може змінювати їх при повторному підключенні.
Використовується багаторівнева консервативна політика перевірки:
1. **GUID тому Windows** (`Volume GUID`).
2. **Серійний номер тому** (`Volume Serial Number`).
3. **Унікальний маркер SyncForge** (`.syncforge_marker`).
4. **Контроль цілісності**: якщо маркер скопійовано на інший диск із відмінним серійним номером, операції запису автоматично блокуються.

---

## 3. Правила фільтрації та маршрутизації

У вкладці **Правила** можна налаштовувати:
- Виключення тимчасових каталогів та файлів (`node_modules/*`, `target/*`, `*.tmp`).
- Маршрутизацію певних форматів у визначені папки (наприклад, `*.pdf` в `Documents/PDF`).
- Обмеження за розміром файлів.
- Запобігання колізіям імен файлів (з урахуванням нечутливості Windows до регістру).

---

## 4. Вирішення конфліктів

Коли файл змінено одночасно на двох накопичувачах:
- **Залишити версію ПК**: копіює версію з комп'ютера на SSD.
- **Залишити версію SSD**: оновлює робочий файл на ПК версією з SSD.
- **Зберегти обидві версії**: створює безпечну копію з суфіксом конфлікту, наприклад `файл_(conflict_1700000000).txt`.
- **Пропустити**: залишає обидві сторони без змін.

---

## 5. Запуск та використання

- Графічний інтерфейс: запустити файл `dist/SyncForge/SyncForge.exe` або команду `syncforge`.
- Консольна діагностика: команда `syncforge-cli devices` або `syncforge-cli profiles`.
